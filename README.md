# Java Programming I & II — MOOC.fi

My solutions for the [Java Programming I and II](https://java-programming.mooc.fi/) MOOCs by the University of Helsinki ([mooc.fi](https://mooc.fi/)).

## About the courses

Java Programming I and II are free, open online courses that teach programming fundamentals using Java. Java Programming I (Parts 1 to 7) covers the basics: printing, variables, conditional statements, loops, methods, lists and the first steps into object-oriented programming. Java Programming II (Parts 8 to 14) builds on it with more advanced object-oriented programming and other topics.

## Repository structure

One folder per part (`part01`, `part02`, ...). Inside each part, every folder corresponds to one exercise from the course, named according to the official MOOC convention (`Part01_XX.ExerciseName`), and contains only my solution (`ExerciseName.java`). Course templates, tests and build files are not included.

## Tech

- **Language:** Java 11 (the version the course requires)
- **Tooling:** TMC (Test My Code) plugin, VS Code
